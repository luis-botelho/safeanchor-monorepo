# 📚 Learning Report — EPIC 001

# Fleet Management Foundation

## Objetivo
Construir a base do SafeAnchor através do gerenciamento de embarcações.

Foi o primeiro módulo do sistema e serviu como fundação para toda a arquitetura do projeto.

---

# Funcionalidades Desenvolvidas

- Cadastro de embarcações
- Listagem
- Atualização
- Exclusão
- Tela de detalhes
- Navegação entre páginas

---

# Arquitetura Implementada

- MVVM
- React Router
- API REST
- Organização por camadas
- Services
- ViewModels
- Models

---

# Conceitos Aprendidos

- CRUD completo
- Fluxo HTTP (GET, POST, PUT e DELETE)
- React Router
- useEffect
- useState
- Componentização
- Comunicação Frontend ↔ Backend
- Organização em camadas

---

# Problemas Encontrados

- Organização inicial da arquitetura
- Fluxo do React
- Estrutura MVVM
- Git Flow

---

# Decisões Arquiteturais

- Adoção do padrão MVVM
- Separação entre Services e Views
- Utilização de ViewModels para regras de negócio
- Organização baseada em Features

---

# Lições Aprendidas
A maior lição desta Epic foi entender que um software não é apenas código.

Arquitetura, organização e planejamento tornam o desenvolvimento mais previsível.
